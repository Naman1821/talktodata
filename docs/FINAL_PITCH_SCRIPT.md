# Final Pitch Script (90 seconds)

## Opening (15s)
We built a self-service assistant so non-technical users can upload **their own** CSV or PDF and get answers **without any cloud AI** — everything runs on the uploaded file in the session.

## Problem (15s)
Teams often struggle with fragmented tools, unclear definitions, and slow analysis cycles. This leads to low confidence and delayed decisions.

## Solution Demo (40s)
1. Upload a CSV with dates and a metric; confirm **File … Loaded Successfully**.
2. Ask a business question (e.g. breakdown by region, or “North vs South”) and show the table, chart, and sources.
3. Upload a PDF and search for words that appear in the text; show matching lines (or **Not present.** when there is no match).
4. Upload a different file to show the session resets.

## Trust and Governance (10s)
CSV answers come from explicit pandas calculations on the upload. PDF answers are lines from extracted text only — no external knowledge.

## Close (10s)
This delivers clarity, trust, and speed in one workflow, with no API keys required for the demo path.
